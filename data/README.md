# Données de contrôle

- [consolidation_source_changes.csv](consolidation_source_changes.csv) : journal champ par champ entre les registres reçus et le registre harmonisé.
- [source_aliases.csv](source_aliases.csv) : URL identiques conservées sous plusieurs identifiants ; ne pas compter plusieurs preuves indépendantes.
- [validation_results.json](validation_results.json) : contrôles structurels reproductibles de cette consolidation.

Ces fichiers suivent le registre de la racine. Les futurs tableaux analytiques doivent citer source_id, document, page, date, période, unité et périmètre.
