# 03_bioenergy

Bioénergie, technologies, marchés et réglementation — booster stratégique du plan GreenUp 2024-2027.

Appliquer les règles du fichier [AGENTS.md](../AGENTS.md). Indexer les documents dans [SOURCES.csv](../SOURCES.csv) (registre d'audit racine faisant foi) et dans [sources/sources_bioenergie.csv](sources/sources_bioenergie.csv) (vue filtrée dédiée à ce booster, même schéma).

## Structure
- `documents/` — synthèses documentaires rédigées à partir des sources collectées (5 dossiers thématiques : booster Veolia, comparables cotés, majors énergétiques, réglementation, M&A/marché).
- `sources/` — `sources_bioenergie.csv`, extension/vue filtrée du registre SOURCES.csv racine, limitée aux sources bioénergie.
