# Transactions — Water Technologies, Clean Earth, tuck-ins 2025, comparable WM/Stericycle

## En bref
Les deux transactions majeures du briefing interne (Water Technologies/CDPQ, Clean Earth/Enviri) sont confirmées mot pour mot par les communiqués officiels. Le prix des trois tuck-ins de juin 2025 reste explicitement non public (le seul chiffre disponible, 350 M$, est un agrégat sur 5 transactions dont 2 internationales, non ventilable). Un seul comparable sectoriel récent solide a été trouvé (WM/Stericycle), sans multiple EV/EBITDA publié.

## Points importants
- Clean Earth doit être utilisé comme baseline **avant intégration** (communiqué Enviri du 21/11/2025) : une fois consolidé chez Veolia (depuis le 01/06/2026), l'actif disparaît dans le segment déchets dangereux du groupe — c'est exactement le point d'attention du briefing interne.
- Aucun communiqué CDPQ distinct trouvé pour la transaction Water Technologies (seule la source Veolia documente officiellement la transaction côté officiel).
- Pas de multiple EV/EBITDA publié pour WM/Stericycle malgré une recherche ciblée — seule une indication qualitative ("nettement inférieur au multiple de cotation de WM") figure dans le communiqué.
